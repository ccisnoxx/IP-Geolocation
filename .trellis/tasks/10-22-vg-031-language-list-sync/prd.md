# VG-031 主语言与语言列表同步

2026-10-22 用户授权：修复切换主语言后旧中文仍残留的问题，保证主语言排第一；调查 Accept-Language 与页面语言一致的实现方式。

依赖 VG-023、VG-024 均已在 task-manifest.yaml 标记 done。

## 实现合同

- Popup 与 Options 的主语言实际变更时，按新主语言、基础语言及英语重建去重列表，不继承旧列表。用户随后仍可显式填写其他备用语言。
- 归一化由 config-model 统一负责：主语言总是排第一，重复主语言删除，其他显式备用语言及其顺序保留；空列表按当前主语言生成，不使用无关地区的旧列表。
- 不批量清除已保存配置中的多语言偏好，不修改独立站点覆盖、权限、注册或每文档快照语义。
- Accept-Language 本轮只调查。现有原生请求头合同保持，不恢复 DNR，不更改用户真实浏览器语言偏好。

## 验证

- 验证配置读取、站点覆盖和生成页面脚本中主语言与列表第一项一致。
