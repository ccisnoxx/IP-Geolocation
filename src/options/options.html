配置引导：检测出口 → 选择站点 → 明确启用

全新安装默认关闭保护，没有预选站点，WebRTC 使用浏览器默认值。可以随时跳过；已有配置升级不会套用这些默认值。

1. 主动检测并确认出口

点击后会请求外部 IP 定位服务，对方可见网络出口。先检查检测结果并确认保存；安装、打开页面和跳过均不会自动检测。

2. 选择站点

所选站点规则将启用、绑定该出口并继承全局信号；原有站点覆盖将被替换。全局位置和时区改为 auto，其他站点与其他信号设置保留；开启总开关也会启用其他已保存的有效规则。页面语言/时区须完成 userScripts 注册后在新文档使用，其他页面伪装仍暂停。未保存的下方表单不参与引导提交。

3. 检查并明确启用

跳过会关闭全局保护、恢复本扩展 WebRTC 默认策略，保留已保存内容。也可直接关闭此页；不会自动启用。

strict 强制使用已启用的语言/时区；compatible 仅补未指定的默认值，保留页面显式 locale/timeZone，可能降低一致性。Date 本地 getter 均使用配置时区；不改变 WebRTC，也不保证规避检测。模式随新文档快照生效；已有文档与 BFCache 不热更新，需完整重载或关闭重开。

字体暴露过滤注册状态尚未确认；未取得确认前按未应用处理，不影响语言/时区注册状态。

获准注册后，匹配白名单的 HTTP(S) 顶层页面 measureText() 仅使用 monospace、sans-serif、serif 测量；具名字体回退为允许的通用字体。FontFaceSet.check() 和普通 iframe 仍过滤内置厂商／软件及简繁中文字体。测量与实际绘制字体可能不同，影响 Canvas 排版及结果图片。不覆盖 DOM 尺寸、@font-face local()、像素比对、OffscreenCanvas 或 Worker。不会随机化 Canvas 图像，也不会修改 WebGL、GPU 或硬件信息。

自定义过滤可能影响网页字体检测与排版兼容性。保存内置模式会替换自定义名单；需要保留时请先导出完整配置。此功能不会隐藏全部系统字体。
