配置引导：检测出口 → 选择站点 → 明确启用

全新安装默认关闭保护，没有预选站点，WebRTC 使用浏览器默认值。可以随时跳过；已有配置升级不会套用这些默认值。

1. 主动检测并确认出口

点击后会请求外部 IP 定位服务，对方可见网络出口。先检查检测结果并确认保存；安装、打开页面和跳过均不会自动检测。

2. 选择站点

所选站点将启用、绑定该出口并继承全局信号；原有站点覆盖将被替换。全局位置和时区改为 auto，其他站点与其他信号设置保留；开启总开关也会恢复其他已启用规则。未保存的下方表单不参与引导提交。

3. 检查并明确启用

跳过会关闭全局保护、恢复本扩展 WebRTC 默认策略，保留已保存内容。也可直接关闭此页；不会自动启用。

Signal Settings

自动跟随 / 手工覆盖

strict 强制使用已启用的语言/时区；compatible 仅补未指定的默认值，保留页面显式 locale/timeZone，可能降低一致性。Date 本地 getter 均使用配置时区；不改变 WebRTC，也不保证规避检测。当前页面伪装仍暂停，保存不会恢复。
