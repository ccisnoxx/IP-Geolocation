VanishGeo Console

环境一致性控制台

统一管理站点白名单、出口 IP 跟随、地理位置、时区、语言和 WebRTC / Canvas 防泄漏策略。

Overview

保护概览

Exit Locations

出口位置档案

档案中的公网 IP、坐标、国家和时区只来自一次完整检测。这里只能修改名称；重新检测必须先确认旧值与新值。

Allowlist

站点白名单

保存域名后，还需要在下方“站点特定规则”为 auto 地理位置/时区显式选择出口位置档案。
Signal Settings

自动跟随 / 手工覆盖

例如：-7 表示 UTC-7，+8 表示 UTC+8

当前策略状态：读取中

Profiles

自定义配置文件

需要固定环境时，将当前手工坐标、时区和语言保存为通用方案。出口身份仍由独立的出口位置档案管理。

Site Rules

站点特定规则

每条规则显式选择出口位置档案；未选择或选择待确认档案时，auto 地理位置和时区不会注入。

Data

数据管理

保存后，只要已打开站点的有效 runtime payload 发生变化，对应标签页会自动刷新。
