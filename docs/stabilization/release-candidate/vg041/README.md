## 发行说明必须保留的限制

- 字体仅既定43项的选择性暴露／测量过滤，名单外字体原生透传；不隐藏 DOM 尺寸、local()、像素或 Worker 字体，自定义名单暂停。
- 仅普通 HTTP(S) 顶层／iframe，语言、时区、定位有各自条件；合成位置不等同原生传感器。每文档快照，旧文档／BFCache／旧 Worker 需完整重建。
- Accept-Language 与页面注册来自同一有效语言配置，但 API 不原子同步。先关闭扩展总开关并等待同步、完整 reload；直接关 Allow User Scripts 可能暂时残留旧语言头。
- Blob 仅页面及已同步链中各 realm 安装后自身新建的 Dedicated Blob Worker；CSP 必须允许入口、依赖和源核验。警告意味着本次未同步并保持原生；Worker URL／import.meta.url／堆栈可观察变化且同步核验有成本。
- HTTP(S) Dedicated Worker、SharedWorker、外来 Blob、未接管父级后代及特殊文档继续暂停／未覆盖；未新增其他设备指纹伪装。
- 既有7份历史附件缺口及首轮恢复异常沿用历史记录；不由本任务补写 PASS。静态产物扫描不保证任意动态 URL 或秘密均不存在，WebRTC 策略不等于全部网络路径防泄漏证明。
